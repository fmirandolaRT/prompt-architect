Pro Tips for Maximum Impact
→ Upload relevant files alongside the prompt — Claude reads PDFs, images, spreadsheets, and code.
→ For documents, explicitly say "Create a .docx file" or "Make a presentation" to get downloadable files.
→ Use "Think step by step" for complex reasoning. Use "Be concise" for quick answers.
→ Say "Search the web for..." when you need current data.
→ Ask Claude to "remember" key facts for use in future conversations.
→ Trigger specific skills: "Use the [skill name] skill" if you have skills uploaded.
→ For long agentic tasks, ask Claude to "use extended thinking" before answering.
→ Iterate: "Good start, now make it more [specific quality]" is how experts use Claude.
