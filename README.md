# Prompt Architect

A web-based prompt engineering helper for Claude. Build high-performance prompts with structured guidance, live scoring, and a complete catalog of Claude's capabilities and connected tools.

**Live demo:** _(set up GitHub Pages on this repo to publish)_

---

## What it does

- **🛠 Builder** — Walk through 6 structured prompt sections (Role, Context, Task, Format, Examples, Constraints) with best-practice tips, hidden feature callouts, and a live 0–100 quality score.
- **⚡ Capabilities & Tools** — Complete reference of Claude's native features, search tools, connected services (MCP), specialized inline tools, and power techniques. NEW items are flagged.
- **📋 Templates** — Six ready-to-copy prompt skeletons for common workflows (technical problems, document creation, code, decisions, communications, skill-based tasks).
- **🏁 Assembled Prompt** — One-click compile your filled sections into a single copy-paste-ready prompt.

## Versioning

Click the **version badge** in the header to view the changelog. The current version and last-updated date are always visible at the top.

## How to use

1. Open `index.html` in any modern browser, **or**
2. Visit the GitHub Pages URL once enabled (Settings → Pages → Deploy from `main` branch / root)

No build step, no dependencies, no backend. Just a single HTML file with vanilla JS.

## Tech

- Pure HTML / CSS / vanilla JavaScript
- Google Fonts (DM Sans + JetBrains Mono) — only external resource
- Fully responsive (desktop + mobile)
- Dark-mode native
